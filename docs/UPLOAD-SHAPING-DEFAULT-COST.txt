Experimental default-traffic cost reduction (from 87d32e0b)

Status: isolated software-path improvement; NOT approved for host activation
or updates. The exact-SHA approved list remains 25dbb1a only. No host state
changes accompany this work. UDP GSO passthrough remains a separate design,
not a queue flag change (see UDP-GSO-REVIEW-PLAN.txt).

Cause isolated
Four variants of the existing netdevsim/TSO/GSO fixture were run forward and
reverse with the same running daemon/firewall, six-second bulk TCP sender and
120 low-rate TCP messages at 50 ms intervals. Existing guest binaries reused.
Rates below are receiver payload / the measured wall window, Mbit/s:
 original fq_codel + daemon                   574 / 575
 static HTB/default fq_codel, empty clsact     568 / 592
 static classifier, no bindings/housekeeping  623 / 520
 full controller + automatic discovery        316 / 314
A second matched sequence separated controller-with-no-caps from discovery:
 static classifier                            587 / 563
 enabled controller, empty caps               405 / 406
 full controller + one idle capped socket     331 / 343
The static classifier's lease expires; its unbound path still executes. No
bound lease or authority was bypassed. All low-rate messages arrived.

CPU accounting includes live descendant self CPU and reaped-child CPU, unlike
the earlier VM7 figures. Short-lived tc/ip/ethtool/probe/kernel children count.
In the first run daemon-tree CPU grew from 68-72 to 219-220 ticks per ~6 s
(HZ=100); in the split run, static 64-73, empty-caps 168-173, full 216-220.
This identifies recurring control-plane work, not HTB alone, as the dominant
measured regression. It does not identify every remaining kernel/daemon cost.

One targeted change
Topology reads now issue five identical fresh queries in one `tc -j -batch -`
process, and all bounded class-parent filter queries in a second. Previously
each query launched another process. No cached topology, fewer checks, longer
leases or slower polling. Mutations remain individual commands bracketed by
the existing write-ahead journal. Dump order is unchanged; neither method is
an atomic kernel snapshot. Nonzero command exit, incomplete/extra JSON arrays,
malformed output or timeout refuse the observation. Class-parent names are
validated before constructing batch input.

Evidence and limits
.workspace/shaping-default-cost contains exact staged hashes, raw records,
logs, four isolation/comparison scripts and README. candidate1 retained a
fixture Applying-state KeyError; candidate2 completed native comparisons and
checks. Model tests: 14 passed; a prior wrong-working-directory launcher failure
is retained as models.log (no tests ran). Native checks compare old and new
query topology, inject a foreign filter and require verification/cleanup refusal,
remove only that fixture filter, verify exact owned restoration, and show Deny
zero delivery with firewall active. Previous cap/live-edit, identity, lease and
crash recovery evidence is reused: those mechanisms did not change. No new
claim that those entire suites ran on this revision.

The committed default-cost/run.py parameterizes the executed scripts via
FLOWGATE_DEFAULT_COST_MODE=isolation|split|candidate|control. Only schedule and
labels differ; raw executed script copies and staged manifests remain in the
evidence directory. It requires the existing disposable guest harness plus
controller-baseline.py (87d32e0b) and controller-candidate.py staged in /work/m1.
Never run this fixture on the host.
