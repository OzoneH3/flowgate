One targeted change
During verify(), include the expected class-parent filter queries with the five
base queries in ONE finite tc -j -batch - invocation. Expected classes select
query targets only: freshly observed classes must equal the expected classes
before the observation is accepted. Added/removed/modified classes refuse the
observation; invalid/duplicate handles and class bounds also refuse it.
All dumps remain fresh and non-atomic. Successful process exit, exact JSON-array
count, 3s timeout and the existing output check remain mandatory.
Preflight and post-mutation discovery still use the original two-phase query,
so newly created classes are fully observed before journaling. Mutations retain
individual write-ahead journal brackets. No persistent helper or dependency,
polling interval, lease, identity, queue or firewall change is introduced.

Rejected experiment
A persistent TC interpreter was tried and measured, then rejected in review:
complete JSON can arrive before a command reports failure. Those measurements
(candidate1/control artifacts) are retained but DO NOT validate this finite
replacement. No persistent-query implementation is included.

A pre-existing empty-census bug was also exposed: Go encodes an empty nil
socket slice as JSON null. The controller now treats only null as an empty
list, withdraws absent bindings, and maintains the heartbeat. Invalid object
output remains an error. Diagnostic startup failures and trace are retained.
